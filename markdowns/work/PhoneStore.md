# 📱 PhoneStore

A fully deployed **eCommerce web application** designed to showcase premium smartphones and accessories with a modern, responsive experience.

# 🔧 Tech Stack

- **Frontend:** Next.js, Redux Toolkit, Tailwind CSS
- **Backend:** Django REST Framework, PostgreSQL, JWT
- **DevOps:** Docker, Render (API), Vercel (Frontend)
- **Payments:** Integrated with PayPal

# 🛍️ Key Features

- Client & Admin login with JWT authentication
- Product listing, category filter, cart & order
- Admin dashboard for product/bill/user management
- Stock level tracking & low inventory alerts
- Secure payments using PayPal
- Fully responsive UI/UX design
